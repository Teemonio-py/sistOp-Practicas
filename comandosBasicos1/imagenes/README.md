# Práctica: Comandos básicos de Linux

## Descripción

En esta práctica aprendimos y utilizamos comandos básicos de Linux para navegar y consultar el contenido del sistema de archivos mediante la terminal. Se practicaron comandos como `ls` para listar archivos y carpetas, incluyendo sus permisos, tamaños y archivos ocultos, así como `cd` para desplazarnos entre directorios y regresar a la carpeta personal (`home`).

### Comandos utilizados

- `ls` — Lista el contenido de la carpeta actual.
- `ls -l` — Muestra información detallada de los archivos, como permisos, propietario, tamaño y fecha.
- `ls -la` — Incluye los archivos ocultos en el listado.
- `ls -lh` — Muestra los tamaños de los archivos en un formato fácil de leer.
- `cd carpeta` — Permite entrar a una carpeta.
- `cd ..` — Sube un nivel en la estructura de directorios.
- `cd ~` o `cd` — Regresa a la carpeta personal del usuario (`home`).

## Objetivo

Familiarizarnos con la terminal de Linux y aprender a realizar operaciones básicas de navegación y consulta de directorios mediante comandos.
